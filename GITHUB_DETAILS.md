# GitHub repository details

**Repository name:** `BCD-Arithmetic-Mini-Processor`

**Short description:** Modular BCD arithmetic circuit in Proteus with addition, subtraction, multiplication, input validation, multiplexer control, and seven segment output.

**Suggested topics:** `digital-electronics`, `proteus`, `bcd`, `logic-circuits`, `arithmetic-circuits`, `multiplexer`, `seven-segment-display`, `computer-engineering`

**Portfolio summary:** Designed and simulated a modular BCD arithmetic mini processor using hierarchical digital logic circuits in Proteus. The system accepts two single digit BCD operands, performs addition, subtraction, or multiplication, and routes the selected result to a seven segment display. Its subcircuits cover input validation, arithmetic, binary to BCD conversion, multiplexers, and operator display logic. The repository includes the native Proteus project, schematic PDFs, a design report, and recorded circuit test cases.
